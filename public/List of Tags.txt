NOTE (2026-08-26): {tgl_cetak} replaces every per-document "tgl_surat_*" tag that used
to sit at the bottom of these letters ({tgl_surat_stkp}, {tgl_surat_smkp},
{tgl_surat_ppkp}; permohonan-kp's {tgl_surat_pmkp} is now moot, see below). It is a real
print timestamp: computed fresh at the moment the student actually clicks "Unduh" (never
cached/reused), for every KP document universally — including perpanjangan-kp, whose
letter date intentionally moved from "date the extension was requested" to "date
printed". See documentGenerator.js: templates + the Cloud Run PDF converter are warmed
ahead of time (on page load) purely to cut latency, but the render itself (and thus
{tgl_cetak}) always happens at click time.

permohonan-kp — REMOVED from the app. Filling this form now happens on an external
website; the student portal only has an upload zone for the resulting file (see
KP_DOKUMEN.permohonan in src/utils/helpers.js). No tags are rendered by the app for this
template anymore.

Magang / Mata Kuliah Terapan (MKT)

Magang and MKT (Mata Kuliah Terapan) are the same program with two twin
template files per document (…-magang.docx / …-mkt.docx) — documentGenerator.js
picks the right file automatically from the student's jenisMagang field. UNLIKE
KP, the Magang/MKT pair of each document does NOT share tag names — every
tag below that contains "magang"/"mkt" is suffixed per file (e.g. judul_magang
in the -magang.docx file vs judul_mkt in the -mkt.docx file); documentGenerator.js
builds both automatically from a single `sfx = jenisMagang === 'MKT' ? 'mkt' : 'magang'`.
Tags without that suffix (no_surat, nama_mhs, nim, nama_dosen1, nip1, tgl_cetak,
nama_dosen_wali, nip_dosen_wali) are named the same in both files.

Tugas Akhir (TA)

Shared by every TA document: {tema_ta} = the Topik/bidang label picked in the
registration form (bidangLabel(m.bidang)). Every TA payload also sends
{tgl_cetak}, {nama_dosen_wali}, {nip_dosen_wali} even where a template doesn't use them.

NOTE (2026-10-12): TA now has 1 Pembimbing + 2 Penguji (Pembimbing 2 removed).
  Sempro & Semhas: Pembimbing + Penguji 1. Sidang: Pembimbing + Penguji 1 + Penguji 2.
  Dosen tags are numbered in that order:
    {nama_dosen1}/{nip1} = Pembimbing (every TA document)
    {nama_dosen2}/{nip2} = Penguji 1 (ba-sempro-ta, ba-expo-ta, ba-sidang-ta)
    {nama_dosen3}/{nip3} = Penguji 2 (ba-sidang-ta only)
  {nama_dosen4}/{nip4} is no longer sent. Templates that still contain a tag the app
  no longer sends will print "undefined" there until the tag is removed from the .docx.
